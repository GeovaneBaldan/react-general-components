# React General Components for VSCode

A VSCode extension for generating React components and utility structures with support for styled-components, hooks, modals, contexts, and more — optimized for web and mobile development.

## ✨ Features

- ⚛️ Generate React functional components for Web or React Native
- 🧭 Guided prompts for platform, structure, variants, and more
- 🎨 Option to use styled-components or not
- 🧱 Supports multiple structures:
  - Components
  - Hooks
  - Contexts
  - Modals
  - API Routes
- 📦 Command to export all files from a directory into an `index.ts`

## 🚀 Getting Started

### 1. Access the Commands

You can run the extension commands in two ways:

- **Via Command Palette**:
  Open the VSCode Command Palette with `Ctrl+Shift+P` or `Cmd+Shift+P` and search for:

  - `Create React Structure`
  - `Export Files to Index`

- **Via File Explorer**:
  Right-click on any folder in your project and select:
  - **Create React Structure**
  - **Export Files to Index**

### 2. Follow the Prompts

The extension will guide you step-by-step through the available options:

- Select platform (Web or Mobile)
- Choose structure (Component, Hook, Modal, etc.)
- Select variants (e.g., with hook, with styling)
- Confirm naming and file destination

## ⚙️ Requirements

- Visual Studio Code `v1.46.0` or higher
- React or React Native project

## 🔧 Extension Settings

This extension does **not support custom settings yet**. Configuration options are handled via prompt selection.
